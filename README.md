
# BusyBank

A simpe application managing an imaginary bank account.

Switch between main branch (Redux) and redux-toolkit-variation branch (Redux Toolkit) to see the different implementations.

<br>

## Tech Stack

**Main:** [Vite](https://vite.dev/), [React.js](https://react.dev/), [Redux](https://redux.js.org/), [Redux Toolkit](https://redux-toolkit.js.org/), [Tailwind CSS](https://tailwindcss.com/)

## Run Locally

Clone the project (main branch for Redux, redux-toolkit-variation for Redux Toolkit)

```bash
  git clone https://github.com/AlexanLiakou/busy-bank.git
```

Go to the project directory

```bash
  cd busy-bank
```

Install dependencies

```bash
  npm install
```

Start the Vite server

```bash
  npm run dev
```
